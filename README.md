# Orca Seaflake Homebrew Cask

This tap provides the Orca Seaflake desktop app for macOS. Install it with:

```sh
brew install --cask femifleming/orca_seaflake/orca-seaflake
```

The Cask downloads the latest Apple Silicon or Intel app bundle from the [Orca Seaflake releases](https://github.com/femifleming/orca_seaflake/releases/latest). The Cask definition is maintained in the main [Orca Seaflake repository](https://github.com/femifleming/orca_seaflake/tree/main/Casks).
